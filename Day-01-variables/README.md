## What I Learned

### var

`var` is an older way to declare variables.

It allows:
- Redeclaration
- Reassignment

### let

`let` is used when the value of a variable may change.

It allows:
- Reassignment

It does not allow:
- Redeclaration in the same scope

### const

`const` is used when a variable should not be reassigned.

It does not allow:
- Redeclaration
- Reassignment

### Redeclaration

Redeclaration means declaring a variable again with the same name.

### Reassignment

Reassignment means changing the value of an existing variable.

### Initialization

Initialization means giving a value to a variable when it is created.
