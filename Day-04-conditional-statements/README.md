# Day 04 - Conditional Statements in JavaScript

## 📚 What I Learned

Today I learned **Conditional Statements in JavaScript**.

Conditional statements are used to make decisions in a program.

## Topics Covered

* `if`
* `if...else`
* `if...else if...else`
* Nested `if...else`
* Logical `&&`
* Logical `||`
* Logical `!`
* Ternary operator `? :`
* `switch` statement
* `break` in switch
* Even and odd checking
* Positive, negative and zero checking
* Age and eligibility checking
* Login and admin checking
* Calculator using switch

## Example

```javascript
let age = 20;

if (age >= 18) {
    console.log("Adult");
} else {
    console.log("Minor");
}
```

## Goal

The goal of Day 04 was to understand how JavaScript makes decisions using conditions.
