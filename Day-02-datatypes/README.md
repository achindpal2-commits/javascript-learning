# Day 02 - JavaScript Datatypes

Today I learned about JavaScript Datatypes.

## Primitive Datatypes

1. String
2. Number
3. Boolean
4. Undefined
5. Null
6. BigInt
7. Symbol

## Non-Primitive Datatypes

1. Object
2. Array

## Practice

* Created examples of each datatype.
* Used `console.log()` to display values.
* Used `typeof` to check datatypes.

## Key Point

Primitive datatypes store simple values.

Non-primitive datatypes store collections of values or more complex data.
